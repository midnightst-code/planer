☁️ Синхронизация
Данные хранятся на jsonbin.io — бесплатном облачном сервисе. После настройки планер будет работать одинаково на Mac и iPhone.
Как получить ключ (2 минуты):
1. Открой jsonbin.io → нажми Sign Up
2. После входа → API Keys в левом меню
3. Нажми + Create Access Key → назови «Планер»
4. Убедись что галочка Store стоит → нажми Create
5. Скопируй ключ (начинается с $2b$) и вставь ниже
Твой API-ключ с jsonbin.io:
Bin ID (заполни если подключаешь второе устройство)
На первом устройстве (Mac) открой ⚙ Синхронизация — там написан Bin ID. Скопируй и вставь сюда.
🔔 Уведомления и напоминания
Напоминания работают, пока планер открыт. Закрытая вкладка или заблокированный телефон могут не показать уведомление.
Статус браузерных уведомлений:

Для всплывающих окон на Mac: Системные настройки → Уведомления → Google Chrome → Разрешить уведомления, стиль «Предупреждения» или «Баннеры» и показ в Центре уведомлений. Планер должен оставаться открытым во вкладке; при закрытой вкладке или спящем компьютере напоминания не гарантируются.

💡 Как указать время задачи: В поле времени рядом с задачей впишите время (например, 14:30 или 09:00). Планер подаст сигнал и заранее, и в точный час!
